# 分级题库「人工复核准入」流程

目标：把一个已建好的级别题库推进到"机器能查的全清零、机器查不了的都列成清单"，让人工复核只做判断、不做排查。

每个阶段都可独立交付：本阶段改了什么文件、跑了什么命令、结果如何、还剩什么风险。用户确认后再进下一阶段。

---

## 阶段 0：准备

| 项 | 做法 |
| --- | --- |
| 备份 | `cp levelN.json levelN.json.bak_<日期>_<原因>`；改题库同理 |
| 标准原文 | 优先找文字版（如 `work/Chinese_standards_no_watermark_djvu.txt`）；扫描件表格段落 OCR 后顺序会乱，只作辅助 |
| 口径 | 先写下分母：本级新增 / 累计；官方表 / 派生表。写进配置，不只在报告里 |

**坑**：PDF 页码换算（内页 + 6）先验证再引用；扫描件里表格是分栏的，`get_text()` 出来的顺序不可信。

## 阶段 1：国标一致性确认

### 1.1 字表（可完全机器验证）

```bash
python - <<'PY'
# 与逐格识别结果做集合比对
cfg = json.load(open('data/levels/levelN.json'))['chars']['new']
ref = json.load(open('work/chars_levels.json'))[str(N)]
print(len(cfg), len(ref), sorted(set(cfg) - set(ref)), sorted(set(ref) - set(cfg)))
PY
```

判据：两侧 300/300，差集为空。顺序不同不算问题（拼音序 vs 标准序）。

结果写进配置：

```json
"chars": { "verified": { "against": "5.x 级汉字表（PDF 页码）", "method": "逐字集合比对", "result": "300/300 一致", "date": "..." } }
```

### 1.2 词表（只能核数量与来源）

- 标准给出的是"本级新增 N 个词"，先核条目数。
- 条目数 > 规范词形数是正常的：标准本身收同形异音/多义（长 cháng/zhǎng、倒 dǎo/dào、得 dé/de、面1/面2……），要逐条说明，不能当成漏词。
- 来源若不是标准 PDF（例如 HSK 3.0 转录），必须在 `verification` 里写明"尚未逐词比对"，不要写成"与标准一致"。

### 1.3 语法点（核编号与条目）

标准附录 A 的编号可读（`【二01】…【二81】`），按序锚定：

```python
g['standard_id'] = '【二%02d】' % index
```

判据：条目数一致、按序一一对应。名称可以保留项目内部写法，但 `standard_id` 必须齐全。

**坑**：如果 `pattern` 字段里存的是中文描述（「结果补语」「存现句」）而不是正则，说明规则从未生效过——这会在阶段 2 炸出来。

### 1.4 音节表（必须拿到官方表）

官方 4.x 表的每一级音节在 100–270 条之间，从扫描图逐条录入即可；**不要用词表反推**，反推出来的表与官方表同源，覆盖率就成了自证。

```json
"syllables": { "status": "official", "entries": 199, "unique": 195, "table": ["a", "ān", ...] }
```

## 阶段 2：覆盖率与读音

### 2.1 语法规则

1. 对每个点跑规则，统计命中数；
2. 命中 <2 的点：先判断是"规则写错/写窄"还是"库里真没这种句子"；
3. 规则写错就重写（模板型名称可程序化，如「爱A不A」→ `爱(.)不\1`）；
4. 库里真没有的，只能补题——需批准。

### 2.2 按国标对齐读音

用词表拼音（含轻声）校正题库拼音，**只改同音不同调**：

```python
if [toneless(c) for c in cur] != [toneless(s) for s in std]: continue   # 音不同不动
```

必须处理 **AA BB 重叠式**（干干净净 = 干 干 净 净）：四字整体取词根读音 ×2，否则会改出一半（`gàn gān`）。

### 2.3 变调

`一`：四声前 `yí`，一二三声前 `yì`；`不`：四声前 `bú`，其余 `bù`。
例外（词表读音，不按变调硬改）：`第一`、`万一` 的「一」读本调 yī；「不」读轻声的词——`差不多` `对不起` `来不及` `了不起` `受不了` `说不定` `看不起` `离不开` `是不是` `能不能`；A 不 A 疑问式（如「对不对」）的「不」也是轻声。
这些例外已写进 `gate.py` 与 `check_sandhi.py`，否则正确读音会被门禁判成错误。

### 2.4 音节覆盖

```
覆盖率 = 官方音节表中，题库读音里出现过的音节数 / 官方音节表音节数
```

缺口分三类：整音节缺失（补题）、同音异调（看词表有没有依据）、儿化与切分噪声（忽略）。

**判据**：整音节缺失必须为 0；同音异调若无词表依据，写成验收条款而不是硬补。

### 2.5 加题（如确需）

加完必须重算：字/词/语法/音节四项覆盖、题量区间、编号连续、与上下级是否重复。

## 阶段 3：准入门禁

```bash
python scripts/gate.py --level N
```

20 项检查，阻断项必须为 0：

结构（6）题量区间、编号连续唯一、level、round、文本无重复、句长区间
形式（3）无字母数字、句末标点、拼音带句末标点
字表（1）无超纲字
拼音（3）汉字音节一一对应、一/不变调、标点体例
标注（2）无空标注、标注与句子相符
（`kind=vocabulary/character` 的跟读题与 `lib.py` 同口径，不要求绑语法点，不计入空标注）
覆盖（3）字/词/语法 100%
重复（1）无跨级重复
提示（若干）近似句比例、音节覆盖声明

**踩过的坑（都是 gate 抓出来的）**：

| 现象 | 根因 |
| --- | --- |
| 拼音标点全没了 | 用 `' '.join(tokens)` 重建拼音，把标点吃掉；必须先拆出标点骨架再替换音节 |
| 文本重复 1 句 | 新增题与已有题撞句 |
| 跨级重复 2 题 | 只在临时副本里改过，仓库未同步 |
| 多音字提示 223 行 | 把 `一/不`（变调）和 `个/服`（轻声）也算进来，噪声盖住真问题 |
| 删重复题后音节覆盖掉了 1 | 被删的那句是某音节的唯一载体；且留下的同句把「脏」读成 zàng（应为 zāng），词表对齐抓不到单字多音字 |

**两条教训**：

1. 增删题目后必须重算四项覆盖与音节覆盖，不能沿用上一轮数字；
2. 单字多音字（脏 zāng/zàng、假、干、数、空、发……）不在多字词对齐的覆盖范围内，只能靠台账的「必看多音字」列交人工，或对真多音字单独跑一遍读音清单。

## 阶段 4：准入报告与台账

产出三样：

1. **准入报告**：20 项检查表（含实测值）+ 本轮修掉的回归 + 交给人工的清单 + 明确写"准入不包含什么"。
2. **复核台账**：每题一行，`必看多音字` 只标真多音字（27 行量级），其余留「—」；空列留给人工。
3. **缺口清单**：词表外词、音节残差、标注待确认项，各自带判定列。

报告必须写清：准入 ≠ 达标；成句、语义、话题难度机器没有判据。
