## 四、语法点（编号与条目）

- 配置 81 条，ID `G3-01`…`G3-81` 连续；按附录 A.3 顺序锚定 `standard_id = 【三01】…【三81】`。
- 标准 A.3 共 81 条（三级累计 210），条目数一致；名称保留项目内部写法，`desc` 中的标准要点与 A.3 顺序一一对应。
- 全库 986 题每题 1 个语法标注，**没有 0 标注、没有少于 2 题的点**，语法覆盖 100% 的前提成立。

### 但规则层有一个必须先修的问题

81 条中有 **32 条**的 `pattern` 存的是中文描述而不是正则，例如：

| 标准编号 | 配置 ID | 当前 pattern | 标注题数 | 命中 |
| --- | --- | --- | --- | --- |
| 【三45】 | G3-45 | `动词或动词性短语\|主谓短语作定语` | 132 | 0 |
| 【三53】 | G3-53 | `主谓谓语句` | 60 | 0 |
| 【三57】 | G3-57 | `表使令` | 38 | 0 |
| 【三54】 | G3-54 | `表处置` | 34 | 0 |
| 【三58】 | G3-58 | `比较句` | 35 | 0 |

这些点合计 **520 个标注与规则不符**，正是门禁 `标注与句子相符` 阻断项的来源。另有 3 条规则过宽（`G3-11` 的 `.` 命中全库、`G3-65` 与 `G3-72` 的 `.*` 分支命中全库）。逐条清单与处理建议见 [三级语法点标准对照.csv](三级语法点标准对照.csv)，阶段 2 按“先重写规则、再看标注是否真的错”的顺序处理。

## 五、音节表与覆盖

### 5.1 官方表录入

来源：标准 PDF **4.3 三级音节表**，内页 11—12（PDF 17—18 页），逐条视读录入 140 条。

- 与标准“三级音节 608 个（新增 140）”吻合，并做了加总校验：**269（一级）＋199（二级）＋140（三级）＝608**。
- 去重后 140 条，**无重复**。第 104 条 `tū` 与第 105 条 `tǔ` 已放大逐字复核，声调不同，不是重复条目；此前误记的 `shǎn` 经放大复核应为 `shàn`（第 93 条），已更正。

### 5.2 覆盖结果

| 指标 | 数值 |
| --- | --- |
| 官方表 | 140 条（去重 140） |
| 题库覆盖 | **139** |
| 覆盖率 | **99.3%** |
| 整音节缺失 | **0** |
| 同音节异调 | 1（`tǎng`） |

### 5.3 唯一缺口 `tǎng`

题库里只有 `tāng`（汤）、`táng`（糖），没有 `tǎng`。经查三级词表，**没有任何词读 `tǎng`**；`躺` 是四级词汇、四级字。补题只能引入超纲词，按方案 A 不补。

验收条款（已写入 `syllables.acceptance`）：

> 覆盖率 139/140 = 99.3%；唯一的缺口（tǎng）为同一音节的不同声调，无音节整体缺失；该读音在国标三级词表中无对应词，补题将引入超纲词，按方案 A 不补，交人工确认。

覆盖数字的分母是**本级新增 140**；若按累计 608 计，分母与口径都不同，不能混用。

## 八、准入不包含什么，以及下一步

本阶段只回答“配置与标准对不对得上”，不回答“题目好不好”：

- 词表只核了数量与来源，**没有逐词比对**；
- 语法点只核了编号与条目，**没有判断标注在语义上是否真的成立**；
- 音节覆盖只说明“题库读音里出现过这些音节”，**不说明读音本身都正确**；
- 成句自然度、语义、话题难度、选项干扰，机器没有判据。

阶段 2 计划（需确认后执行）：

1. 重写 32 条描述性规则 + 3 条过宽规则，先让规则能命中已标注的句子；命中不了的再判断是规则窄还是标注错；
2. 按国标词表读音校正题库拼音（只改同音不同调），处理 AA BB 重叠式；
3. 修 `一/不` 变调 1 处、跨级重复 1 题；
4. 重算字/词/语法/音节四项覆盖；
5. 再跑 20 项门禁，生成准入报告与复核台账。

另：配置 `source_note` 仍写“共374题”，与实测 986 题不符；阶段 2 写配置时一并更正。

> 阶段 1 的结论是“标准与配置已对齐”，**不是“题库可以进入人工复核”**。后者要等阶段 3 的 20 项门禁全部不阻断。
