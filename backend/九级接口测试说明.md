1. `scripts/lib.py`：新增 `SUPPORTED_LEVELS = 1—9` 与 `default_bank(level)`；`load_level` 对越界等级报“超出支持范围（1—9）”，对缺失配置报“等级 N 的配置不存在 + 待标准确认指引”；`load_bank` 对缺失题库报明确中文错误。
2. `scripts/pipeline.py` / `validate.py` / `stats.py`：清除“一级”写死文案，报告标题与路径按 `reports/levelN/` 组织；`--bank` 缺省取 `banks/levelN/final.json`；新增脚本目录 `sys.path` 注入，任意工作目录均可运行。
3. `backend/main.py`：`level` 参数统一限定 1—9（越界 422）；空题库标准响应改为 `{"total":0,"items":[],"detail":"该等级题库尚未完成"}`；新增 `GET /api/levels` 九级状态总览；版本升 0.3.0。
4. `backend/import_bank.py`：`--bank` 缺省按 `--level` 取 `banks/levelN/final.json`；导入摘要按等级分行打印；`--level` 限 1—9。
5. 测试：新增 `backend/test_levels.py`（33 项九级接口测试）；`backend/test_api.py` 回归并更新 2 项断言（越界等级改判 422），现共 46 项。
