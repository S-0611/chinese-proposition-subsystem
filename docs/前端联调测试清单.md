# 前端联调测试清单

## 一、联调前准备

- [ ] 已从 `main` 拉取最新代码。
- [ ] 已确认后端启动命令。
- [ ] 已确认实际接口地址和端口。
- [ ] 已确认返回字段名称。
- [ ] 已准备一级题库测试数据。
- [ ] 没有把真实学生信息、录音或密码用于公开测试。

## 二、题库总览

- [ ] 页面可以打开。
- [ ] 可以选择等级。
- [ ] 可以加载题目。
- [ ] 题目编号显示正确。
- [ ] 等级显示正确。
- [ ] 中文文本显示正确。
- [ ] 逐字拼音显示正确。
- [ ] 语法点显示正确。
- [ ] 题目状态显示正确。
- [ ] 录音数量显示正确。

## 三、题目查询接口

- [ ] `GET /api/questions?level=1` 请求成功。
- [ ] 返回题目均属于请求等级。
- [ ] 只返回允许查看或已入库的题目。
- [ ] 返回字段完整。
- [ ] 查询空结果时页面有明确提示。
- [ ] 后端关闭或网络失败时页面有错误提示。

## 四、按等级抽题

- [ ] `GET /api/questions/random?level=1` 请求成功。
- [ ] 返回题目等级正确。
- [ ] 文本和 `tokens` 一一对应。
- [ ] 返回题目编号可保存。
- [ ] 未入库题目不会被抽出。

## 五、按覆盖程度推荐抽题

- [ ] `GET /api/questions/recommend?level=1` 请求成功。
- [ ] 无录音题目优先级高于已有录音题目。
- [ ] 低录音量题目优先级高于高录音量题目。
- [ ] 加权随机没有固定返回同一题。
- [ ] `last_selected_at` 能记录最近抽取时间。
- [ ] 页面显示录音数量。

## 六、流水线页面

- [ ] 出题入口存在。
- [ ] 校验结果页面存在。
- [ ] 统计结果页面存在。
- [ ] 缺口清单可以显示。
- [ ] 补题入口存在。
- [ ] 入库状态可以显示。
- [ ] 只有达标题目可以发布。

## 七、学生端和管理端联调

- [ ] 学生端可以按等级调用题目接口。
- [ ] 学生端可以同时显示文本和逐字拼音。
- [ ] 题目编号可以和后续录音关联。
- [ ] 管理端可以按等级查询题目。
- [ ] 管理端可以按编号查询题目。
- [ ] 命题端和管理端的题目数量一致。
- [ ] 题目状态和录音数量口径一致。
