# 二至九级等级配置规范化说明（2026-11-22）

## 一、为什么改

原 `data/levels/level2—level9.json` 是标准统计口径（chars 平铺、grammar 只有条数），
`scripts/pipeline.py` 读取时直接 `KeyError: 'constraints'`，接入真实题库时跑不通。
本次按 `level1.json` 的模板做结构转换，目标只有一个：**题库交付后 pipeline 能直接跑**。

## 二、改了什么

- 统一字段：`level / name / tier / source_note / constraints / thresholds / chars / grammar`。
- `chars` 改为 `{"all", "core", "new"}`：`all` 为累计字表（一级起逐级并入新增字），`new` 保留本级新增字表；`core` 暂无依据，留空。
- `grammar` 改为数组（level1 同款 `[{id,name,pattern,desc}]`）。标准附录 A 的语法点清单未随文件交付，**当前留空**，并写入 `grammar_note` 说明应补条数与附录编号。
- `constraints`：`min_chars` 一级 3，二级 4；`max_chars` 二级按《命题流水线说明》第九节建议取 16，之后逐级 +4；题量沿用一级 `[110, 280]`；均标“暂定待确认”。
- `thresholds`：覆盖率阈值沿用一级；语法清单为空的等级把 `grammar_coverage_min` 置 0、`grammar_freq_min` 置 0（门禁关闭，接入清单后要改回 1.0 / 2）。
- 7—9 级没有分级字表（标准高等阶段只给累计/新增计数），`chars.all` 留空，`char` 门禁同步关闭，并在 `chars.note` 写明待补 5.8.3 手写表与认读表。
- 转换脚本：`scripts/normalize_levels.py`，可重复执行（幂等需先还原原始文件）；`--check` 只检查不写盘。

## 三、引擎侧配套改动

- `scripts/lib.py`：`validate_item` 在字表/语法清单为空时跳过对应检查并给 warning，不再 KeyError；字段缺失时用安全默认值。
- `scripts/stats.py`：字表或语法清单为空时跳过对应门禁，`notes` 字段输出“待补，门禁未启用”；`render_md` 增加“说明”段。
- 一级行为不变：`pipeline --level 1` 仍 300/300 字、42/42 语法点、结论达标。

## 四、验证结果

- `python scripts/smoke_levels.py`：2—9 级配置全部可读、可校验、可统计（6 题冒烟题库，结论 fail 属预期，字覆盖/题量不足）。
- `python scripts/pipeline.py --level 1 --tag normcheck`：达标（无回归）。
- `python scripts/pipeline.py --level 2 / 7 --bank <冒烟题库>`：正常输出校验、统计、调整计划，退出码 2（未达标），无异常。
- `python backend/test_levels.py`：33/33；`python backend/test_level23.py`：20/20。

## 五、还缺什么（接入真实题库前）

1. 语法点清单：二级 81 条（附录 A.2）、三级 81（A.3）、四级 76（A.4）、五级 71（A.5）、六级 67（A.6）、七至九级 148 条（A.7，不再分级）。按 `{id,name,pattern,desc}` 补进 `grammar`，并把 `grammar_coverage_min` 改回 1.0、`grammar_freq_min` 改回 2。
2. 核心字表：标准没有“核心字”表，一级的 128 字属自定义；二至九级暂空，需要项目负责人定口径后补 `chars.core`。
3. 7—9 级字表：需补高等认读 3000 字 / 新增 1200 字、手写 1200 字（5.8.3），否则只能跑，不能做字表越界校验。
4. 累计字数与标准不一致：二级累计 550（标准 600）、三级 838（900）、四级 1133（1200）、五级 1431（1500）、六级 1730（1800）。原因是项目一级字表为整理口径，与标准 5.1 未逐字对齐，与二至六级新增表存在重叠（二级 50 字、三级 12 字、四级 5 字、五级 2 字、六级 1 字）。建议后续用官方 5.1 字表校准一级，重叠会自然消失。
