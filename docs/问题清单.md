## 问题上报格式

遇到问题时不要只写“不会”或“运行不了”，请按以下格式记录：

```text
问题标题：
我想完成的任务：
执行的命令或操作：
完整错误信息：
已经尝试过：
相关文件和行号：
是否阻塞：
需要谁协助：
```

## 问题分级

- 阻塞问题：导致当天任务无法继续，需要立即在群里报告。
- 一般问题：有替代方案，当天记录并集中处理。
- 优化问题：不影响主流程，放入后续清单。
