# 统一接口字段

## 题目对象

为兼容命题端已有页面，接口保留 `id`、`text`；三端联调统一使用以下字段：

```json
{
  "id": "L1-001",
  "question_id": "L1-001",
  "question_version": "1",
  "content_revision": "sha256...",
  "level": 1,
  "text": "我姓王，你姓什么？",
  "display_text": "我姓王，你姓什么？",
  "tokens": [
    {"c":"我", "py":"wo3", "display_py":"wǒ", "display_start":0}
  ],
  "grammar": ["G1-04"],
  "status": "published",
  "rec_count": 0,
  "last_selected_at": null
}
```

- `question_id` 是命题端稳定题号；`id` 仅为兼容旧客户端保留。
- `question_version` 是发布版本；当前旧题库默认版本为 `1`。
- `content_revision` 是题文和规范拼音内容的 SHA256 摘要，用于识别内容变化。
- `display_text` 保留原文标点。
- `tokens` 只按发音字排列；`py` 为小写数字声调，轻声为 `5`、`ü` 统一为 `v`。
- `display_py` 保留页面展示所需的带调拼音。
- `display_start` 是按 Unicode 码点计算的原文起始位置，不是 UTF-16 下标。

## 题目接口

```text
GET /api/questions?level=1&status=published
GET /api/questions/{question_id}
GET /api/questions/random?level=1&n=1
GET /api/questions/recommend?level=1&n=1
```

列表返回 `{ "total": n, "items": [...] }`；随机和推荐返回 `{ "level": n, "mode": "...", "items": [...] }`。

## 录音计数

```text
POST /api/questions/{question_id}/recorded
```

请求体可带 `recording_id` 和匿名 `speaker_id`。同一个 `recording_id` 重试不重复增加 `rec_count`；重录必须生成新的 `recording_id`。

## 覆盖快照

```text
PUT /api/v1/integration/coverage
```

请求体必须包含 `snapshot_version`、带时区的 `generated_at` 和 `items`。每项包含 `question_id`、`recording_count`、`unique_speaker_count`。同一版本重复提交必须幂等。
