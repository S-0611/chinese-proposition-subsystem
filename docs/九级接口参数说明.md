# 九级接口参数说明

- 服务基址：`http://127.0.0.1:8001`（启动：项目根目录 `python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001`）
- 在线文档：`http://127.0.0.1:8001/docs`（Swagger UI）
- 等级约定：`level` 为整数，**取值范围 1—9**；越界（0、10 等）统一返回 `422`
- 数据组织：等级数据 `data/levels/levelN.json`，题库 `banks/levelN/`，报告 `reports/levelN/`
- 后端版本：`0.3.0`（本次起支持一级至九级按等级查询）

## 一、查询接口

### 1. GET /api/questions

按等级（可再叠加状态）查询题目。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| level | int | 否 | 等级 1—9；缺省返回全部等级 |
| status | str | 否 | `draft` / `validated` / `rejected` / `ready` / `published`；非法值返回 400 |

正常响应（有题目）：

```json
{
  "total": 256,
  "items": [ { "id": "L1-001", "level": 1, "text": "…", "tokens": […], "grammar": […], "status": "…", "rec_count": 0, "last_selected_at": null } ]
}
```

空题库响应（该等级尚未建库）——**标准样例见 `docs/九级空题库返回示例.json`**：

```json
{
  "total": 0,
  "items": [],
  "detail": "该等级题库尚未完成"
}
```

说明：未建库等级返回 200 + 标准空题库响应，**不会返回其他等级的题目**（防串题由按 `level` 过滤保证，见测试第 2/3 组）。

### 2. GET /api/levels

九级题库状态总览（供状态看板使用），无需参数。

```json
{
  "total": 9,
  "items": [
    { "level": 1, "question_count": 256, "status": "available", "detail": null },
    { "level": 2, "question_count": 0, "status": "pending", "detail": "该等级题库尚未完成" }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| status | `available` = 有题目可查询；`pending` = 题库尚未完成 |
| detail | `pending` 等级固定为“该等级题库尚未完成” |

### 3. GET /api/questions/{qid}

按题目 id 查询单题（id 全局唯一，如 `L1-001`）。不存在返回 404。

## 二、抽题接口

### 4. GET /api/questions/random

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| level | int | 是 | 等级 1—9 |
| n | int | 否 | 抽取数量，默认 1，上限 20；超过存量时按存量返回 |

仅从该等级 `published` 题目中等概率抽取。该等级无已发布题目返回 404。

### 5. GET /api/questions/recommend

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| level | int | 是 | 等级 1—9 |
| n | int | 否 | 抽取数量，默认 1，上限 20 |
| C | float | 否 | 权重常数，默认 10，须 > 0 |
| candidate_size | int | 否 | 候选集大小，默认 20，须 ≥ 1 |
| recent_minutes | int | 否 | 短时防重复窗口（分钟），默认 10，可为 0 |

权重公式：`w = max(0, C - rec_count)`。该等级无已发布题目返回 404。

## 三、记录与状态接口

### 6. POST /api/questions/{qid}/recorded

请求体（均可空）：`{ "recording_id": "…", "speaker_id": "…" }`。`rec_count + 1`；同一 `recording_id` 重放不重复计数。

### 7. POST /api/questions/{qid}/status

请求体：`{ "status": "…" }`。状态流转受 `STATUS_FLOW` 约束，非法流转返回 400；发布必须走 `/publish` 门槛，不允许直改 `published`。

### 8. POST /api/questions/{qid}/publish

单题发布。门槛 = 自动校验通过 + 整级统计达标 + 人工复核（`reports/levelN/manual_review.json`）无未解决 P0。

## 四、流水线接入接口

### 9. POST /api/pipeline/validate?level=N

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| level | int | 否 | 等级 1—9，默认 1 |

对库内该等级全部题目跑校验，结果落盘 `reports/levelN/api_validate_<时间>.json`。未建库等级返回 404（detail 说明“该等级题库尚未完成”）。

### 10. POST /api/pipeline/stats?level=N

参数同上。对库内该等级题目跑覆盖统计与调整计划，落盘 `reports/levelN/api_stats_<时间>.json`。未建库等级返回 404。

### 11. POST /api/pipeline/publish

请求体：`{ "level": 1 }`（1—9）。整级发布门槛与单题一致，通过后把该等级 `ready/validated/draft` 题全部置为 `published`。

### 12. PUT /api/v1/integration/coverage

管理端覆盖快照接入（按 `snapshot_version` 幂等），与等级无关，契约不变。

## 五、错误码约定

| 状态码 | 场景 |
| --- | --- |
| 200 | 正常查询；未建库等级返回标准空题库响应 |
| 400 | 非法 status、非法状态流转、发布门槛不通过 |
| 404 | 题目不存在、该等级无已发布题目、未建库等级的操作类接口 |
| 422 | `level` 越界（<1 或 >9）、`n` 超上限、请求体字段不合法 |

## 六、与 0.2.0 的差异

1. 空题库响应字段由 `message` 改为标准 `detail`（值固定为“该等级题库尚未完成”），响应形状见 `docs/九级空题库返回示例.json`。
2. `level` 全部接口统一限定 1—9，越界返回 422（0.2.0 允许任意正整数）。
3. 新增 `GET /api/levels` 九级状态总览接口。
4. 流水线脚本（`scripts/`）同步支持 `--level 1—9`，报告路径按 `reports/levelN/` 组织，不再出现“一级”写死文案。
