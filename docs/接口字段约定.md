# 接口字段约定

本文件保留为旧命题端客户端的兼容说明。三端联调以 [`统一接口字段.md`](./统一接口字段.md) 为准。

## 兼容字段

命题端继续返回 `id`、`text`、`tokens`、`grammar`、`status`、`rec_count`、`last_selected_at`，避免旧页面失效。

## 统一字段

新增并优先使用：

```text
question_id
question_version
content_revision
display_text
tokens[].c
tokens[].py
tokens[].display_py
tokens[].display_start
```

## 接口地址

命题端联调地址为 `http://127.0.0.1:8001`：

```text
GET /api/questions?level=1&status=published
GET /api/questions/{question_id}
GET /api/questions/random?level=1&n=1
GET /api/questions/recommend?level=1&n=1
POST /api/questions/{question_id}/recorded
PUT /api/v1/integration/coverage
```

旧客户端使用的 `http://127.0.0.1:8000` 仅作为历史记录，不再用于三端联调。

## 七至九级合并

七、八、九级按标准合并为 `level 7`。`level=8`、`level=9` 为别名，后端统一按 `level=7` 查询、校验、统计、发布和抽题；响应保留 `requested_level`，并返回 `merged_into: 7`。客户端优先直接使用 `level=7`。
