# 接口字段约定

## 一、题目返回结构

```json
{
  "id": "L1-001",
  "level": 1,
  "text": "我姓王，你姓什么？",
  "tokens": [
    {"c": "我", "py": "wǒ"},
    {"c": "姓", "py": "xìng"},
    {"c": "王", "py": "Wáng"}
  ],
  "grammar": ["G1-04"],
  "status": "published",
  "rec_count": 0,
  "last_selected_at": null
}
```

## 二、字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 全库唯一题目编号，例如 `L1-001` |
| `level` | integer | 题目所属等级 |
| `text` | string | 题目中文文本 |
| `tokens` | array | 汉字和逐字拼音的对应数组 |
| `tokens[].c` | string | 单个汉字 |
| `tokens[].py` | string | 该汉字的带声调拼音 |
| `grammar` | array | 实际命中的语法点编号 |
| `status` | string | 题目状态 |
| `rec_count` | integer | 已成功保存的有效录音数量 |
| `last_selected_at` | string/null | 最近一次被抽取的时间 |

## 三、题目状态

```text
draft       待校验
rejected    校验不合格
validated   校验通过
ready       统计达标、待发布
published   已入库，可被接口抽取
```

只有 `published` 状态的题目可以返回给学生端。

## 四、接口

### 按等级查询题目

```text
GET /api/questions?level=1
```

用途：命题页面、管理端按等级查看题目。

### 按编号查询题目

```text
GET /api/questions/{id}
```

用途：查看单道题目完整字段。

### 按等级随机抽题

```text
GET /api/questions/random?level=1
```

用途：学生端按等级获取题目。

### 按历史覆盖程度推荐抽题

```text
GET /api/questions/recommend?level=1
```

用途：优先返回没有录音或录音数量较少的题目。

推荐逻辑：先筛选指定等级中录音数量最低的一批候选题，再使用：

```text
w = 1 / (1 + rec_count)
```

进行加权随机，并结合 `last_selected_at` 避免短时间连续返回同一道题。

## 五、错误返回建议

```json
{
  "detail": "未找到等级为1的已入库题目"
}
```

## 六、联调前必须确认

- 实际接口前缀和端口。
- 返回结果是数组还是 `{ "questions": [] }`。
- 录音数量的统计口径。
- 同一学生重录是否计入 `rec_count`。
- 管理端是否需要题目增删改权限。
