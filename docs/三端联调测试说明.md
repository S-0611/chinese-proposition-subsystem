# 三端联调测试说明

## 端口与启动

| 服务 | 端口 | 启动方式 |
|---|---:|---|
| 学生端 | 8000 | 由学生组提供 |
| 命题端 | 8001 | `python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001` |
| 管理端 | 8765 | 由管理组提供 |

命题端初始化与导入：

```powershell
python backend/init_db.py --reset
python backend/import_bank.py
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
```

## 学生端取题验收

1. 学生端访问 `GET http://127.0.0.1:8001/api/questions?level=1&status=published`。
2. 响应为 `{ "total": n, "items": [...] }`，每个题目包含统一题目字段。
3. 学生端保存 `question_id`、`question_version`、`content_revision` 和完整 `question_snapshot`。
4. `tokens` 使用 `c`、规范化数字声调 `py`；页面显示使用 `display_py`。
5. 练习记录中的题号必须来自命题端，不能重新生成演示编号。

## 录音回传验收

学生端保存一条有效录音后调用：

```http
POST /api/questions/{question_id}/recorded
Content-Type: application/json

{"recording_id":"stable-client-recording-id","speaker_id":"anonymous-speaker-id"}
```

同一个 `recording_id` 重试时，命题端返回 `duplicate: true`，`rec_count` 不重复增加。每次重录应使用新的 `recording_id`。

## 管理端覆盖统计验收

管理端按题生成带版本快照并调用：

```http
PUT /api/v1/integration/coverage
Content-Type: application/json

{
  "snapshot_version": "2026-week2-v1",
  "generated_at": "2026-11-19T18:00:00+08:00",
  "items": [
    {"question_id":"L1-001", "recording_count":3, "unique_speaker_count":2}
  ]
}
```

同一 `snapshot_version` 重放必须返回 `applied: false`，不能再次累加。当前接口完成了本地幂等存储；正式环境仍需三组确认服务身份认证和 HTTPS 部署方式。

## 本地自动测试

```powershell
python backend/test_api.py
```

测试覆盖服务信息、统一字段、查询、校验、统计、发布、随机抽题、推荐抽题、录音幂等和覆盖快照幂等。测试使用独立数据库，不修改正式 `backend/bank.db`。

## 人工验收记录

人工测试需要记录：测试日期、服务地址、测试账号角色、题目编号、请求与响应、截图、PR/commit 和是否通过。真实学生姓名、邮箱、录音和密码不得写入公开仓库。
