# 后端启动说明

> 成员B（李勃霖）· 2026-11-19
> 命题子系统后端：FastAPI + SQLite，统一端口 **8001**。

## 1. 环境要求

1. Python 3.11+。
2. 依赖：`fastapi`、`uvicorn`、`pypinyin`。
3. 安装：`pip install fastapi uvicorn pypinyin`。

## 2. 启动步骤（项目根目录执行）

```powershell
# 第 1 步：初始化数据库（已有 bank.db 可跳过）
python backend/init_db.py --reset

# 第 2 步：导入一级题库（banks/level1/final.json，256 题）
python backend/import_bank.py

# 第 3 步：启动后端
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
```

## 3. 访问入口

1. 服务信息：http://127.0.0.1:8001/
2. Swagger 文档：http://127.0.0.1:8001/docs
3. 全部题目：http://127.0.0.1:8001/api/questions
4. 一级题目：http://127.0.0.1:8001/api/questions?level=1
5. 单题查询：http://127.0.0.1:8001/api/questions/L1-001

## 4. 预期输出

```text
INFO:     Uvicorn running on http://127.0.0.1:8001
```

服务信息返回示例：

```json
{
  "service": "命题子系统后端",
  "version": "0.2.0",
  "questions_total": 256,
  "docs": "/docs"
}
```

## 5. 常见问题

1. 端口占用：换端口启动，如 `--port 8002`，同时前端请求地址也要同步修改。
2. 题量为 0：先执行导入脚本 `python backend/import_bank.py`。
3. 抽题接口 404：题目需先发布（`POST /api/pipeline/publish {"level":1}`），只有 `published` 题可被抽取。
4. 完整接口说明见 [docs/接口说明初稿.md](./接口说明初稿.md)，返回示例见 [docs/接口返回示例.md](./接口返回示例.md)，数据库生成与表结构见 [docs/数据库生成说明.md](./数据库生成说明.md)。
