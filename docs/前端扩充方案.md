# 前端扩充方案

## 一、目标

在现有中文发音智能诊断与评价系统 V2 演示页面的视觉和角色结构基础上，增加命题人员端功能。保留学生端、教师/研究员端和管理端已有功能，命题页面作为教师端或命题人员端的新增入口。

## 二、页面范围

命题人员端新增：

1. 题库总览：按等级查看题目，显示编号、文本、逐字拼音、语法点、状态和录音数量。
2. 题目详情：查看单道题目的完整字段和逐字拼音。
3. 出题：录入等级、文本、逐字拼音和语法点，提交前做基础字段检查。
4. 校验结果：显示校验总数、合格数、不合格数和逐题错误原因。
5. 统计结果：显示字覆盖率、字频、语法点覆盖率和缺口清单。
6. 补题与入库：查看缺口、补充题目、显示题目状态，并将达标题目发布入库。
7. 抽题测试：按等级抽题，按历史覆盖程度推荐抽题，并显示录音数量。

## 三、与现有 V2 的整合原则

- 保留现有登录、学生端、教师端、管理端和统一样式。
- 命题功能作为新增页面和导航入口，不替换原有页面。
- 前端先使用脱敏示例数据完成页面结构，再接入后端真实接口。
- 不上传真实学生信息、真实录音、明文密码或含隐私的演示数据到公开仓库。

## 四、页面开发顺序

```text
题库总览
→ 题目详情
→ 校验结果
→ 统计结果
→ 补题/入库
→ 抽题测试
→ 学生端和管理端联调
```

## 五、当前阶段成果

当前仓库中的 `frontend/` 先保存命题页面原型。后端接口完成后，将把示例数据替换为真实请求，接口地址和字段以 `接口字段约定.md` 为准。
