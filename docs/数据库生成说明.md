# 数据库生成说明

> 成员B（李勃霖）· 2026-11-18
> 数据库文件 `backend/bank.db`（SQLite）不直接提交（.gitignore 已忽略 `*.db`），任何人可用下面两步随时重建，保证"数据库文件或生成说明"可交付。

## 1. 生成步骤（项目根目录执行）

```powershell
# 第 1 步：建库（--reset 可选，用于删除旧库重建）
python backend/init_db.py --reset

# 第 2 步：导入真实一级题库（banks/level1/final.json，256 题）
python backend/import_bank.py
```

导入结果核对：

```text
[import] 源题库：banks/level1/final.json，共 256 题
[import] 新导入 256 题，跳过 0 题
[import] 数据库现有 256 题，其中一级 256 题
```

## 2. 表结构

1. `questions`：id（主键）、level、text、tokens（JSON）、grammar（JSON）、status、rec_count、last_selected_at。
2. `run_records`：kind（import/validate/stats/publish/draw/record/status）、level、detail（JSON）、created_at。每轮校验、统计、发布和抽取都会留痕。

## 3. 初始状态

1. 新导入的题 status 为 `ready`，rec_count=0，last_selected_at 为 null。
2. 发布须走接口 `POST /api/pipeline/publish {"level":1}`（自动做整体达标检查），只有 `published` 题可被抽题接口返回。
3. 重复运行 import_bank.py 不会覆盖已有题目的 rec_count / last_selected_at 等运行字段；如需完全重置用 `--force`。

## 4. 后端启动命令

```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

- Swagger：http://127.0.0.1:8000/docs
