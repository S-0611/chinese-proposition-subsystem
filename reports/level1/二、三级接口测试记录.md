## 三、自测脚本（可直接粘贴执行）

```bash
# 1) 二级：条数与等级纯度
curl -s "http://localhost:8000/api/questions?level=2" > l2.json
python3 - <<'PY'
import json
d=json.load(open('l2.json'))
items=d['items'] if isinstance(d,dict) and 'items' in d else d
print('count', len(items))
print('level purity', {i['level'] for i in items})
print('L1 ids', sum(1 for i in items if str(i['id']).startswith('L1-')))
print('field ok', all(i.get('text') and i.get('pinyin') and i.get('grammar') for i in items))
PY

# 2) 三级：同上，把 level=2 换成 level=3、l2.json 换成 l3.json
```

## 四、判定标准

- 通过：条数与预期一致（或 `total` 一致）、`level` 单一、无低级别 id、字段非空。
